# Aether

**Polymorphic Native Kernel**

Aether — это экспериментальное полиморфное ядро, которое не принадлежит ни одной операционной системе.  
Оно является нейтральным носителем *личностей* (Personalities): Linux, Android и Windows.

Личности загружаются только когда нужны и могут быть полностью выгружены из памяти.

## Ключевые принципы

- Нет постоянной хостовой ОС
- Нет классической эмуляции процессора
- Нет традиционных виртуальных машин как основы
- Linux, Android и Windows — равноправные нативные личности
- Экстремальная ленивость: код и данные личности существуют в памяти только пока используются
- Единое capability-based ядро

## Текущий статус

Проект только создан. Архитектура находится в стадии проектирования.

## Структура репозитория

```
aether/
├── docs/                  # Документация и архитектура
│   ├── architecture/
│   ├── design/
│   └── roadmap/
├── kernel/                # Код самого ядра Aether
│   └── src/
│       ├── arch/          # Архитектурно-зависимый код
│       ├── mm/            # Менеджер памяти
│       ├── sched/         # Планировщик
│       ├── ipc/           # Межличностное взаимодействие
│       ├── capability/    # Capability-система
│       └── personality/   # Загрузчик и менеджер личностей
├── personalities/         # Реализации личностей
│   ├── linux/
│   ├── android/
│   └── windows/
├── tools/                 # Вспомогательные инструменты
└── scripts/               # Скрипты сборки и запуска
```

## Цели первой версии (v0.1)

- Минимальный загружаемый Microvisor/Kernel на x86_64
- Capability-модель
- Динамическая загрузка и выгрузка личностей
- Базовая Linux-личность (запуск простых ELF)
- Каркас Windows-личности (PE-загрузчик + минимальные syscalls)

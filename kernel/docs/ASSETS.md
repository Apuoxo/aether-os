# Aether GUI Assets

## Icons
Source: **Original Aether pixel art** inspired by classic desktop metaphor (computer, folder, recycle bin, etc.).
Not Microsoft Windows XP proprietary icons.
License: Created for Aether OS project — free to use with Aether.

Format: 32×32 RGBA, generated at runtime in `gui/icon.rs` (IconId enum).

## Fonts
Currently: built-in 8×8 bitmap font in `graphics.rs`.
Future: embed legal bitmap/TTF-derived bitmaps (e.g. public-domain or OFL fonts converted offline).

## Theme
XP-inspired colors/metrics in `gui/theme.rs` — original Aether values matching classic desktop aesthetics, not extracted from Windows binaries.

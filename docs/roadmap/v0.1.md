# Aether v0.1 Roadmap

## Цель версии

Получить минимально работающее ядро, которое:
- Загружается на x86_64
- Имеет базовую capability-систему
- Умеет загружать и выгружать личности
- Может запустить простой Linux ELF-процесс
- Имеет каркас Windows-личности (загрузка PE + несколько syscalls)

## Этапы

### Этап 1: Каркас ядра
- [ ] Минимальный boot (UEFI или multiboot)
- [ ] Переход в long mode
- [ ] Базовый physical memory allocator
- [ ] Простейший page frame allocator
- [ ] Early console (VGA или serial)

### Этап 2: Виртуальная память и процессы
- [ ] Управление page tables
- [ ] Адресные пространства процессов
- [ ] Создание/уничтожение процессов
- [ ] Простейший планировщик (cooperative или basic preemptive)

### Этап 3: Capability-система
- [ ] Capability-объекты
- [ ] Таблицы capabilities у процессов
- [ ] Базовые операции (mint, revoke, transfer)

### Этап 4: Менеджер личностей
- [ ] Формат модуля личности
- [ ] Загрузка личности в память
- [ ] Регистрация syscall-таблицы личности
- [ ] Выгрузка личности и освобождение памяти

### Этап 5: Linux-личность (минимальная)
- [ ] ELF-загрузчик
- [ ] Минимальный набор Linux syscalls (exit, write, brk, mmap...)
- [ ] Запуск простого "Hello World"

### Этап 6: Каркас Windows-личности
- [ ] PE-загрузчик
- [ ] Минимальный набор NT-совместимых вызовов
- [ ] Запуск простейшей консольной PE-программы

## Критерии готовности v0.1

- Ядро загружается
- Можно запустить Linux Hello World
- После завершения процесса Linux-личность может быть выгружена
- Есть работающий каркас загрузки Windows-личности
- Документация архитектуры актуальна

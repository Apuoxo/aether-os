# Aether v0.1 Roadmap

## Historical status

This document is retained as the original v0.1 plan. It is not a current task checklist.

Much of the original v0.1 foundation has since been implemented, while the Personality compatibility goals remain incomplete.

## Original goals

- x86_64 bootable kernel;
- capability model;
- Personality management;
- basic Linux execution;
- Windows Personality skeleton.

## Current disposition

| Original item | Current status |
|---|---|
| x86_64 boot | Implemented |
| Long mode / native x86_64 runtime | Implemented |
| Physical memory allocator | Implemented |
| Paging | Implemented |
| Process/address-space foundation | Implemented/partial |
| Capability tables | Implemented/partial |
| Personality manager | Foundation implemented |
| Real dynamic Personality modules | Not implemented |
| Linux ELF execution foundation | Implemented |
| Linux compatibility Personality | Not implemented |
| Windows PE Personality | Not implemented |
| Windows compatibility | Not implemented |

## Why this remains

The original v0.1 acceptance criteria assumed that a small Personality implementation would quickly follow the kernel foundation. In practice the project expanded into real hardware, storage, graphics and desktop bring-up.

The roadmap is therefore kept as historical context instead of pretending the old checklist is the current project state.

# Aether v0.2 Status

## Historical status

This document records an earlier roadmap snapshot. It must not be used as the current status of the repository.

## What was subsequently implemented

Since the original v0.2 snapshot, the codebase has progressed substantially in:

- native kernel/userspace foundation;
- Ring3/process infrastructure;
- capability enforcement primitives;
- storage and NTFS work;
- Intel Gen6 graphics bring-up;
- native desktop/windowing;
- terminal and desktop applications;
- HDA audio bring-up;
- Intel 2230 Wi-Fi bring-up;
- MP3/media pipeline.

## What remains incomplete

The original Personality claims in this document were too strong for the current implementation. The current truth is:

- Personality Manager: foundation implemented;
- full dynamically loaded Personalities: not implemented;
- Linux compatibility layer: not implemented;
- Android runtime: not implemented;
- Windows PE/NT compatibility layer: not implemented.

## Current source of truth

Use:

- docs/STATUS.md for current engineering status;
- docs/architecture/overview.md for current/target architecture;
- docs/design/personality_system.md for Personality requirements.

Historical roadmap documents should describe history, not override current source/test evidence.

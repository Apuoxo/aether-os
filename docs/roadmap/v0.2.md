# Aether v0.2 Status

## Historical status

This document records an earlier roadmap snapshot. It must not be used as the current status of the repository.

Since that snapshot, the codebase has advanced in native kernel/userspace, Ring3/process infrastructure, capabilities, storage/NTFS, Intel Gen6 graphics bring-up, native desktop/windowing, HDA bring-up, Intel 2230 transport bring-up and MP3/media support.

The original Personality claims were too strong for the current implementation:

- Personality Manager: foundation implemented;
- full dynamically loaded Personalities: not implemented;
- Linux compatibility layer: not implemented;
- Android runtime: not implemented;
- Windows PE/NT compatibility layer: not implemented.

Use `docs/STATUS.md`, `docs/architecture/overview.md` and `docs/design/personality_system.md` as current sources of truth.

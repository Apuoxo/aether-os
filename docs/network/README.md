# Network

Сетевая документация Aether OS для целевого ноутбука Fujitsu LIFEBOOK AH532.

- [Wi‑Fi / Intel Centrino Wireless‑N 2230](WIFI_AH532.md) — аппаратный профиль, текущий native driver state и пошаговый план реализации.

## Разделы в работе

- Wi‑Fi — Intel 2230 (`8086:0887`, subsystem `8086:4062`).
- Ethernet — Realtek RTL8111/8168 family.
- Общий native network API — будет документирован по мере стабилизации драйверов.
- DHCP/IP/ARP — после появления рабочего сетевого интерфейса.
- BIOS/ACPI radio state — отдельное исследование.
